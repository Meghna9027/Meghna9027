# 💫 About Me:

I'm a Senior Software Engineer (SDE-2) with 4+ years of experience at a high-growth, product-based startup, architecting full-stack systems—from backend services to customer-facing platforms—now live across 60+ business locations pan-India. My work focuses on performance, reliability, and clean system design—because shipping code is easy, but scaling it sustainably is what matters.
 
### What I do best:
 
Architect end-to-end platform features spanning backend services, data flows, and customer-facing interfaces
Design real-time systems for billing, inventory, and notifications integrating multiple third-party providers
Build SEO-optimized, high-performance web experiences that drive customer acquisition
Establish reliable release practices through code review standards and CI/CD pipelines
Mentor engineers and partner across Product, Design, and QA to ship on tight timelines
 
### Impact I’ve delivered:
 
Cut manual operational effort by 87% by redesigning core workflows across appointments, scheduling, and inventory
Improved payment success and inventory accuracy by 90% through real-time billing and inventory re-architecture
Contributed to 400,000+ customer acquisitions via performance-optimized marketing experiences
Reduced page load times by 85% and grew organic traffic by 80% on a customer-facing marketing site
Cut backend response times by 35% while sustaining 99%+ data consistency in production pipelines
Resolved 100+ production incidents through root-cause analysis, strengthening platform stability
Raised core product performance scores from ~55 to 90+, improving user experience and retention
 
### What I’ve built:

My key project is a platform now live across 60+ clinics pan-India, spanning appointments, real-time billing, inventory management, and a notification system powering order, delivery, and consultation alerts at scale.
